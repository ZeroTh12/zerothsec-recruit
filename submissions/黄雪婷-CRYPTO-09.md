| 参数 | 含义 | 本题取值 |
| --- | --- | --- |
| p ､ q | 两个大素数,相乘得到模数 | 473398607161 与 4511491 |
| n | 公开模数,等于 p 乘 q | 2135733555619387051 |
| φ(n) | 欧拉函数,等于 (p−1)(q−1) | 2135733082216268400 |
| e | 公钥指数,须与 φ(n) 互素 | 17 |
| d | 私钥指数, e 关于 φ(n) 的模逆元 | 待求 |
python
标准写法
p = 473398607161 q = 4511491
e = 17
phi = (p - 1) * (q - 1)
d = pow(e, -1, phi) # Python 3.8+ 才支持第三参数求逆元
print(d) # 125631357777427553
print(f"flag{{{d}}}") # 大括号在f-string 中要双写
