# ZEROTHSEC · 网络安全工作室招新站

江工职院网络安全工作室（ZEROTHSEC）2026 秋季招新网站。纯静态多页站点，无后端依赖。

## 页面结构

| 页面 | 文件 | 内容 |
| --- | --- | --- |
| 00 首页 | `index.html` | 工作室介绍、四条战线方向、靶场入口 |
| 01 专业 | `major.html` | 网络空间安全专业档案：课程路线、能力画像、就业方向、证书 |
| 02 招新 | `recruit.html` | 招新时间线、方向要求、工作室铁律、FAQ、报名邮件生成器 |
| 03 CTF | `ctf.html` | 动态新手靶场：22 道题库随机抽 4 题、每人独立 flag、像素小游戏 |

## 本地运行

```bash
npm install
npm run dev
```

浏览器访问终端显示的地址（默认 `http://127.0.0.1:5173/`，若本机 loopback 被拦截可用局域网 IP 访问）。

## 部署

站点为纯静态文件，GitHub Pages 直接从仓库根目录发布即可（已包含 `.nojekyll`），无需构建步骤。

## 说明

- 报名表单仅在本机生成邮件草稿，不收集、不上传任何数据。
- CTF 题库位于 `assets/data/challenges.json`，flag 按浏览器会话签发，校验全部在本地完成。
- 具体招新安排与数据以学院官方发布为准。
