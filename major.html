网络空间安全
不只是“修电脑”。

它研究的是：当数据离开你的设备之后，如何仍然只被该看见的人看见。 这是一门关于信任、边界与对抗的工程学科。

WHAT IS IT

一门把“信任”拆开来看的学科 TRUST, BUT VERIFY

你每天扫码登录、上传作业、连接校园 Wi-Fi。每一次点击背后，都有一串请求穿过网络，抵达你看不见的服务器。网络空间安全要做的，就是设计并验证这条链路上的每一道边界。

你会学计算机网络，知道数据包如何从 A 走到 B；会学操作系统，知道进程、权限与内存如何工作；会学 Web 与渗透测试，知道攻击者如何寻找缝隙；也会学应急响应与取证，知道当缝隙被撕开时，如何止损与复盘。

它不是“会用一个黑客工具”，而是理解工具背后的原理，并能在授权范围内，用工程化的方式解决问题。

  • DEF.01
    保密性 / Confidentiality只有被授权的人能看到。
  • DEF.02
    完整性 / Integrity数据没有被悄悄改写。
  • DEF.03
    可用性 / Availability需要时，服务仍然在。
  • DEF.04
    对抗性 / Adversarial对手会持续进化，所以你也必须。

03
CAREER PATHS

毕业后，你可能会站在这些位置 FOUR DIRECTIONS

C.01 渗透测试工程师PENETRATION TESTER 在授权范围内模拟真实攻击，验证系统能否扛住，并把过程写成可复现、可修复的报告。 WEB / 内网 / 报告
C.02 安全运营工程师SOC ANALYST 盯着告警与日志，把海量噪声过滤成可行动的线索，让一次异常在变成事故前被拦下。 SIEM / 日志 / 编排
C.03 应急响应工程师INCIDENT RESPONDER 事件发生时，按预案止损、取证、溯源与复盘。需要冷静，也需要平时把流程练熟。 取证 / 溯源 / 预案
C.04 安全开发工程师SECURITY ENGINEER 把安全能力写进产品和研发流程：代码审计、SDL、自动化工具，而不是等出事后打补丁。 SDL / 审计 / 工具

岗位名称与要求会随行业变化；此处只描述典型工作内容，不构成就业承诺。
